# Tabrik — Mustaqillik Ekspressi 🇺🇿

Temiryo'lchilar uchun Mustaqillik bayrami tabrik sayti. Ikkita versiya bor:

| Papka | Nima | Qanday ochiladi |
|---|---|---|
| [react-app/](react-app/) | **Asosiy versiya** — React + TypeScript + Vite | `cd react-app`, `npm run dev` |
| [mustaqillik-ekspressi/](mustaqillik-ekspressi/) | Eski versiya — bitta `index.html` fayl | `index.html` ni brauzerda ochish kifoya |

Ikkalasida ham: tungi osmon, yulduzlar, oy, haqiqiy lokomotiv videosi (`train.mp4`),
"Tabrikni ochish" tugmasi bilan tabrik oynasi va konfeti. React versiyada qo'shimcha:
sayt ochilganda 4 soniyalik zar-gul yomg'iri.

Saytni internetga chiqarish uchun `react-app` ichida `npm run build` qilib,
`dist/` papkasini istalgan hostingga (Netlify, Vercel, GitHub Pages) yuklash mumkin.
